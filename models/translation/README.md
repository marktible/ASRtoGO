# Translation models

Place your own llama.cpp-compatible translation `.gguf` files here.
Setup does not download any models. The web app detects new files when Settings
is refreshed; no reinstall is needed. PLaMo translation models use the existing
source/target language chat-template settings. Compatibility with other chat
templates depends on the model.

Keep all files belonging to a split GGUF together. Select its first shard.
