# Speech recognition models

Place your own CrispASR-compatible ASR `.gguf` or Whisper `.bin` files here.
Setup does not download models. Refresh Settings to discover files.
Keep tokenizer/vocabulary and other companion files required by your model
beside it. Select only the main model file; format support depends on CrispASR.

The ASR backend uses Vulkan. A model's GPU support depends on its architecture.
